# AxoRuneLostWorlds

## Characters

Every character is a template file in `config/arlw/characters/<name>.json`.
A player whose nickname is a valid character name (`A-Z`, `0-9`, `_`) gets a character with the same name on first join.
A player with any other nickname gets a random character from the existing templates.

### Official character pack

Download: https://github.com/JimForse/AxoR.U.N.E-LW/releases/latest/download/arlw-characters.zip

Unpack the archive into `config/arlw/characters/` on the server (or in the game folder for singleplayer), then restart or run `/character custom reload`.
